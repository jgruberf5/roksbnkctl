# Decisions

The running decision log for this deployment. The solution-architect owns it.
One entry per non-trivial choice — record the alternative you rejected and why,
so the next engineer (and the final report) can trace the reasoning.

## Template

```
## <date> — <decision title>
- Context: <what prompted the choice>
- Decision: <what we chose>
- Alternatives rejected: <option> — <why not>
- Consequences: <what this commits us to / costs>
```
