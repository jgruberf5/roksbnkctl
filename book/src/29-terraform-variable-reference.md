Auto-generated by `go run ./tools/refgen/tfvars-md > book/src/29-terraform-variable-reference.md`. Re-run on every `terraform/variables.tf` change.

Every variable below is settable via `terraform.tfvars`, `-var`, `-var-file`, or (for sensitive values) the corresponding `TF_VAR_<name>` environment variable. Variables with `_required_` defaults must be set explicitly. See [Chapter 13](./13-terraform-variables.md) for how roksbnkctl threads these through the workspace config.
